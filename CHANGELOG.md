## [9.0.0](https://github.com/BazZziliuS/VoteFlow/releases/tag/v9.0.0) — 2026-11-26

VoteFlow 9.0 — отдельное расширение со своим ID, вдохновлённое Auto Vote Rating и созданное на основе его кода.

> **Важно: перенесите данные вручную.** Новый ID означает новое расширение для браузера, поэтому проекты и настройки старого Auto Vote Rating или VoteFlow 8.x не подхватываются автоматически. Если просто поставить 9.0, рядом окажутся два расширения, и оба будут голосовать.

### Как перейти
1. В старом расширении откройте **Настройки → Экспортировать настройки** — сохранится файл `.json` с проектами и настройками
2. Удалите старое расширение на странице расширений браузера
3. Установите VoteFlow 9.0 ([инструкция](https://github.com/BazZziliuS/VoteFlow#установка))
4. В VoteFlow откройте **Настройки → Импортировать настройки** и выберите сохранённый файл

Если вы ставите VoteFlow впервые, ничего переносить не нужно.

### Что изменилось
- Собственный ID расширения вместо унаследованного от Auto Vote Rating
- Описание проекта: VoteFlow — новое расширение, вдохновлённое Auto Vote Rating

Кнопки «добавить в Auto Vote Rating» на сайтах серверов вели к старому расширению и с VoteFlow не работают — добавляйте проекты ссылкой или через окно расширения на странице сервера.

## [8.3.2](https://github.com/BazZziliuS/VoteFlow/releases/tag/v8.3.2) — 2026-11-26

### Исправлено
- **minecraftrating.ru.** Сайт обновил страницу проекта, и расширение не находило кнопку голосования. ## [8.3.0](https://github.com/BazZziliuS/VoteFlow/releases/tag/v8.3.0) — 2026-11-26

### TopCraft снова работает
- Голосование переписано под новый сайт TopCraft: окно голосования на странице сервера, результат во всплывающем сообщении
- **Автовход через VK ID.** Если вы не вошли на TopCraft, расширение входит само через ВКонтакте (нужно быть залогиненным на vk.ru в этом браузере) и возвращается голосовать
- **Yandex SmartCaptcha.** Расширение само протягивает слайдер «Потяните вправо». Если Яндекс попросит дополнительное задание, придёт уведомление пройти капчу вручную, после чего голос уйдёт сам
- Проекты TopCraft, которые раньше были отключены, снова включаются автоматически

### Капчи
- SmartCaptcha распознаётся на новых доменах Яндекса: smartcaptcha.cloud.yandex.ru и captcha-api.yandex.ru (также помогает minecraftrating.ru)
- Невидимая проверка Cloudflare Turnstile больше не останавливает голосование

### Сайты
- Исправлено голосование на 15 сайтах после их обновлений: curseforge.com, listforge.net, mclike.com, minecraft.buzz, minecraftbestservers.com, minecraftservers.org, planetminecraft.com, serveur-minecraft-vote.fr, serveur-prive.net, discords.com, mmotop.ru, minecraft-server.eu, top.gg, topg.org, top-games.net
- Новые сайты: minerank.com, topeaglerservers.com, voxelrank.com, 16bitmc.net

Исправления сайтов и обработка Turnstile перенесены из форка [JustMordeckai/Auto-Vote-Rating](https://github.com/JustMordeckai/Auto-Vote-Rating) (MIT), см. THIRD_PARTY_NOTICES.md.

### Исправлено
- Переход к проекту из уведомления или окна расширения падал с ошибкой «Cannot read properties of null (reading 'scrollIntoView')»

### Разрешения
- Добавлен доступ к id.vk.ru (вход через VK ID), smartcaptcha.cloud.yandex.ru и captcha-api.yandex.ru (капча Яндекса). После обновления браузер может попросить подтвердить доступ

## [8.2.0](https://github.com/BazZziliuS/VoteFlow/releases/tag/v8.2.0) — 2026-11-26

### Новое
- **Добавление проекта с открытой страницы.** Откройте свой сервер на сайте-рейтинге и нажмите на иконку VoteFlow. Расширение предложит добавить проект: ссылка подставится в форму, останется указать ник. Если проект уже добавлен, будет кнопка «Открыть»

- **«Сообщить о проблеме» у проекта с ошибкой.** Ссылка открывает на GitHub уже заполненную заявку с сайтом, текстом ошибки и версией. Ваш ник в неё не попадает

### Разрешения
- Добавлено `activeTab`. Расширение видит адрес текущей вкладки только в момент, когда вы нажимаете на его иконку

## [8.0.0](https://github.com/BazZziliuS/VoteFlow/releases/tag/v8.0.0) — 2026-11-25

Auto Vote Rating теперь называется **VoteFlow**. Проект продолжает расширение [Auto Vote Rating](https://github.com/Serega007RU/Auto-Vote-Rating), автор оригинала — Serega007.

### Новое
- Новое имя, логотип и тёмный интерфейс страницы настроек
- Проекты показываются карточками. Цветная точка обозначает статус: запланирован, в очереди, голосует сейчас, ошибка. Рядом с датой следующего голоса — сколько осталось («через 3 ч 12 мин»)
- Режимы проекта (приоритет, рандом, тихий режим) показаны отдельными метками
- Удаление проекта в два клика вместо одного
- Статистика с крупными главными цифрами
- Подсказки к полям и настройкам видны сразу, без наведения
- Название расширения на странице расширений ведёт на GitHub проекта

### Исправлено
- Импорт настроек из старой резервной копии падал с ошибкой
- Капча hCaptcha и проверка Cloudflare не обрабатывались: скрипт падал раньше
- Тихое голосование могло перестать работать после перезапуска фонового процесса браузера
- minecraft-server.sk: проект нельзя было добавить по ссылке
- Не работала опция «свой таймаут только в последний день месяца»
- magicrust.gg: бесплатный кейс снова находит кнопку «Открыть кейс»
- Быстрое добавление не показывало кнопку «Повторить» при ошибке
- Opera: ошибка при выборе сайта в ручном режиме добавления
